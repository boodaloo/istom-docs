# Ведомости врача

#### Где находятся ведомости врача?

В левом меню пункт "Ведомости", раздел "Расход", подраздел "Врач". Здесь находится полная информация по всем врачам. Также много полезной информации есть в меню "Прочие ведомости".

---

## Виды отчётов в разделе «Прочие ведомости»

### Сводный отчёт

Сводный отчёт формируется за определённый период, который следует указать до формирования отчёта. Отчёт имеет особенность: выборка данных идёт из **составленных счетов**, а не из проведённых оплат. Если дата составления счёта выходит за рамки указанного периода — такой счёт не попадёт в сводный отчёт, даже если оплаты по нему были в этом периоде.

### Реестр оплаченных счетов пациентов

Отчёт формирует данные за указанный период и выводит информацию о **всех оплатах по счетам** за этот период. Носит общий характер — не содержит полной информации по составу счетов, но включает достаточное количество финансовых данных.

### Отчёт «Зарплата-Врач»

Формирует таблицу, отсортированную по фамилиям врачей, с информацией об оказанных услугах и оплаченных счетах за указанный период. **Требует отдельной настройки** — по умолчанию (до указания врачей в таблице настройки процента от работ) отчёт пустой.

### Реестр счетов

Список всех счетов за период с возможностью фильтрации по различным критериям.
