# Работа с модулем ЕГИСЗ — отправка данных о приёме

## Требования перед отправкой

При каждом посещении пациента необходимо:

1. **Уточнить согласие пациента** на передачу данных в ЕГИСЗ.
   - Если пациент **не согласен** — распечатать «Отказ о предоставлении персональных данных» (раздел «Административная» → иконка красного принтера).
   - Если пациент **согласен** — запросить: СНИЛС, паспортные данные, номер телефона, адрес проживания.

2. Данные о посещении передаются **в течение рабочего дня** (допустимо на следующий день в порядке исключения).

3. Документы, направляемые в РЭМД, **подписываются тем же врачом**, который проводил приём. В поле «Должность» должна быть указана специализация, совпадающая с указанной в ФРМР у этого сотрудника.

!!! tip "Без подписи организации"
    Начиная с определённого обновления документы не обязательно подписывать ЭЦП клиники. Достаточно подписать ЭЦП врача — для этого выставьте галочку **«Не использовать подпись организации»**.

## Пошаговая отправка данных

### Шаг 1. Открыть окно отправки

В карточке пациента нажмите кнопку **ЕГИСЗ** (появляется при активном модуле).

![](../../images/extracted/ЕГИСЗ/image1.png)

### Шаг 2. Авторизация

При первом запуске за сессию откроется окно авторизации в ЛК iStom — поля логина и пароля заполнятся автоматически. Подтвердите авторизацию.

![](../../images/extracted/ЕГИСЗ/image4.png)

После успешной авторизации во второй вкладке будет получен и отображён токен клиента.

![](../../images/extracted/ЕГИСЗ/image5.png)

### Шаг 3. Заполнение параметров отправки

Откроется окно параметров отправки данных в ЕГИСЗ:

![](../../images/extracted/ЕГИСЗ/image6.png)

**Блок данных пациента** (заполняется автоматически):

- ФИО
- Номер карты
- Тип документа (по умолчанию «Паспорт гражданина РФ», можно изменить)

**Блок доверенного лица** — заполняется автоматически, если пациент имеет поручителя.

**Врачебный блок — вкладка «Данные - врач»**:

- Врач, ФИО
- Врач, СНИЛС № *(обязательное поле)*
- Должность *(по умолчанию «Врач-стоматолог»)*

!!! warning "Важно"
    В поле «Должность» должна быть указана корректная специализация врача — такая же, как указана в Федеральном Регистре Медицинских Работников (ФРМР) у этого сотрудника.

**Врачебный блок — вкладка «Данные – пользователь ЕГИСЗ»**:

- Пользователь, ФИО *(обязательное поле)*
- Пользователь, СНИЛС № *(обязательное поле)*
- Должность и Специальность

### Шаг 4. Блок результатов приёма

Заполните обязательные поля:

| Поле | Описание | По умолчанию |
|------|----------|--------------|
| **Код МКБ10** | Выбирается из справочника или вводится вручную | К02 : Кариес зубов |
| Вид мед. обслуживания | Выпадающий список | Специализированная медицинская помощь |
| Состояние пациента | Выпадающий список | Удовлетворительное |
| Оплата | Выпадающий список | Платные услуги |
| Цель визита | Выпадающий список | Лечебно-диагностический приём |
| Результат обращения | Выпадающий список | Выздоровление |
| Поле «Комментарий» | Не обязательное | — |

!!! note "Код МКБ10 — обязательное поле"
    Выберите код из списка. Если нужного кода нет — переключитесь на вкладку «Задать вручную» и введите код самостоятельно.

![](../../images/extracted/ЕГИСЗ/image8.png)

### Шаг 5. Отправка

Нажмите кнопку **Отправить**.

- При успешной отправке — выдаётся сообщение об успехе.
- При ошибке — выводится описание ошибки.

!!! warning "Важное замечание"
    Успешная отправка в программе iStom **НЕ ГАРАНТИРУЕТ** добавления документа в базу ЕГИСЗ, если данные в подписях и полях настроек ошибочные и не соответствуют записям из ЛК РосМинЗдрава.

## Отправка данных для пациента с поручителем

При вызове окна из карты пациента с поручителем:

- Данные **представителя** (поручителя) автоматически заполняются в блоке «Доверенное лицо»
- Данные **подопечного** (пациента) — в блоке «Пациент»
