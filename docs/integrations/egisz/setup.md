# Настройка модуля ЕГИСЗ

## Предварительные требования

- Учётная запись в личном кабинете iStom с присвоенным идентификатором клиники
- Установленная система **КриптоПро версии 5 и выше** на каждом ПК
- Доступ к личному кабинету на портале РосМинЗдрава: [portal.egisz.rosminzdrav.ru](https://portal.egisz.rosminzdrav.ru)
- В ЛК РосМинЗдрава должны быть заданы записи организации (клиники) и врачей в соответствии с сертификатами
- Носитель с ключами КриптоПРО должен быть **подключён к ПК**

## 1. Настройка подписей и сертификатов

Откройте **Настройки программы → Параметры для ЕГИСЗ**.

Для настройки работы с КриптоПро в этом окне необходимо:

1. **Выбрать служебный каталог** — папка, в которую будут записываться файлы подписей и xml-документы перед отправкой. Галочка «Каталог привязан к пользователю» позволяет настроить каталог отдельно для каждого пользователя.

2. **Ввести текст** для наименования документа по умолчанию.

3. Выбрать вкладку **«Режим внешней подписи»**, выставить галочку **«Автоматический режим»**, ввести серийные номера сертификатов из КриптоПро.

4. **Ввести серийные номера** сертификатов клиники и врача (значения берутся из свойств сертификата в программе КриптоПро).

5. **Выбрать ФИО врача** из списка для данного ПК — чья подпись будет использоваться в электронных документах.

6. Выставить галочку **«Открепленная подпись»** (обязательно).

7. При необходимости указать **нескольких врачей**, которые могут использовать сертификаты для подписи.

8. **Указать наименование организации** — должно совпадать с наименованием в ЛК РосМинЗдрава.

9. **Указать OID** — код организации в системе РосМинЗдрава.

10. **Указать номер лицензии** организации.

11. При наличии подразделения — также указать OID и наименование подразделения (рекомендуется скопировать из ЛК).

12. Для ручного указания специальности врача при отправке — выставить галочку **«Разрешить специальности врачей»**.

!!! note "Персональная настройка"
    Указанные настройки вводятся 1 раз для одного ПК. Для другого пользователя на том же ПК также должны быть введены серийные номера, его сертификат должен быть добавлен в КриптоПро, а ключ — подключён к ПК.

## 2. Общие настройки ЕГИСЗ для клиники

Для подключения клиники к сервису ЕГИСЗ необходимо заполнить (один раз для всей клиники):

- **ID LPU** — идентификатор клиники, выданный ЕГИСЗ
- **GUID** — авторизационный токен

Раздел настройки: **Основное меню → Интеграция сервисов → вкладка ЕГИСЗ**.

!!! info "Права доступа"
    Вкладка ЕГИСЗ доступна только пользователю-администратору программы. Настройка записывается в базу данных клиента iStom.
