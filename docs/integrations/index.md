# 🔌 Интеграции

iStom поддерживает интеграцию с различными внешними сервисами для расширения функциональности.

---

## Доступные интеграции

### :material-cellphone: [Мобильное приложение](mobile-app/index.md)
Доступ к системе iStom с мобильных устройств.

**Возможности:**
- Просмотр расписания
- Карта пациента
- Работа с документами
- Доступно для Android и iOS

[Подробнее →](mobile-app/index.md)

---

### :material-phone: [Телефония](telephony/index.md)
Интеграция с IP-телефонией для автоматизации звонков.

**Поддерживаемые системы:**
- Stream
- Mango Office
- UIS

**Возможности:**
- Автоматическое всплывание карты при звонке
- История звонков
- Запись разговоров

[Подробнее →](telephony/index.md)

---

### :material-cloud: [Облачное хранилище](cloud/index.md)
Автоматическое резервное копирование в облако.

**Поддерживаемые сервисы:**
- Яндекс.Диск
- Собственное облако iStom

[Подробнее →](cloud/index.md)

---

### :material-export: Внешние системы
Экспорт данных во внешние программы.

**Доступные экспорты:**
- [Экспорт в 1С](external-systems/1c-export.md)
- [Экспорт в Excel](external-systems/excel-export.md)
- Выгрузка базы данных
- Экспорт телефонов пациентов
