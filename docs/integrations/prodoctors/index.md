# Интеграция ПроДокторов.ру

Интеграция позволяет транслировать расписание врачей из iStom на сайт ПроДокторов.ру. Пациент видит расписание, выбирает удобное время, заполняет форму. Телефонный бот соединяет пациента и клинику, после записи в расписание с баланса клиники снимается оплата за результативный контакт.

## Что необходимо сделать

1. Обратиться в отдел продаж ПроДокторов.ру.

2. Заключить договор на обслуживание.

3. Получить доступ к "Вход в информационный кабинет API" — получить логин и пароль в технической службе ПроДокторов.ру.

4. Предоставить сайту ПроДокторов.ру информацию о стоматологии и о врачах, работающих в стоматологии.

5. В программе iStom корректно заполнить **график работы врачей**, расписание которых будет публиковаться на сайте ПроДокторов.ру.

6. Предоставить в техническую службу iStom данные своего профиля на сайте ПроДокторов.ру (из п.3) для настройки и включения интеграции.

7. Ввести в программе iStom данные для интеграции:

    **ПроДокторов (Расписание) → Войти → ОК → Заполнить поля**

!!! info "Изображения"
    Скриншоты настройки будут добавлены при обновлении документации.

## Как это работает

Расписание транслируется на сайт ПроДокторов.ру из iStom. Пациент заходит на сайт, видит расписание выбранного врача, выбирает удобное время и заполняет регистрационную форму с номером телефона.

Телефонный бот соединяет пациента и клинику. После завершения разговора и записи пациента в расписание (администратор делает запись) с баланса клиники в ПроДокторов.ру снимается оплата за результативный контакт.

!!! tip "Важно"
    Если записи в расписание после телефонного разговора не было — деньги с баланса стоматологии в ПроДокторов.ру не снимаются.
