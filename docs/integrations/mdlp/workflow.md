# Работа с МДЛП (Честный знак)

После выполнения [настройки МДЛП](setup.md) в программе iStom на вкладке **Склад** появится дополнительный раздел **МДЛП (Честный знак)** с соответствующими пунктами меню.

## Проверка статуса подключения

Нажмите на флажок в правом нижнем углу программы iStom:

- **Соединение установлено** — иконка: карточка и буквы "ЧЗ"
- **Соединение не установлено** — иконка: минус и буквы "ЧЗ" (ошибка настройки или нет интернета)

!!! info "Изображения"
    Скриншоты иконок и интерфейса будут добавлены при обновлении документации.

## Регистрация выдачи лекарственных препаратов

1. В окне склада выберите позиции номенклатуры для расходования.
2. Выберите пункт меню по МДЛП → перейдите в окно **Список товаров для списания**.
3. При необходимости измените доли расходования упаковок (если расходуется полностью — числитель 1, знаменатель 1).
4. Считайте или введите **SGTIN** с упаковки → нажмите Enter. В документ добавляются только позиции с заполненным SGTIN.
5. Нажмите **Создать документ** — будет добавлен новый учетный документ для системы МДЛП.
6. В окне **Список Документов по МДЛП** нажмите **Регистрация Выдачи** для выбранного документа.
   - При успехе: сообщение с кодом документа в системе.
   - При ошибке: сообщение об ошибке.

!!! note "Примечание"
    В данной версии допускается повторная регистрация препаратов и создание дублирующих документов с последовательными номерами. Корректность состава зарегистрированных документов пользователь контролирует самостоятельно.

Списанные по МДЛП товары можно также посмотреть в личном кабинете Честного Знака: **Реестр документов → Отправленные**.
