# МДЛП (Честный знак)

Интеграция iStom с системой маркировки лекарственных препаратов **МДЛП (Честный знак)** позволяет вести учёт и списание маркированных лекарств напрямую из программы.

## Разделы

- [Настройка МДЛП](setup.md) — первоначальная настройка интеграции
- [Работа с МДЛП](workflow.md) — регистрация выдачи препаратов, проверка статуса подключения
