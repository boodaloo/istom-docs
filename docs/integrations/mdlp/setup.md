# Настройка МДЛП (Честный Знак)

## Начало работы

Запустите iStom, в разделе **Администрирование** нажмите **Интеграция сервисов**, затем откройте вкладку **Настройки МДЛП (Честный знак)**.

!!! info "Изображения"
    Скриншоты настройки будут добавлены при обновлении документации.

!!! warning "Полная инструкция"
    Подробная пошаговая инструкция доступна в личном кабинете: [cloud.i-stom.ru](https://cloud.i-stom.ru/login) в разделе **Скачать**.

Инструкция написана подробно и содержит **оглавление** для быстрой навигации по разделам.
