## Пояснение по работе с локальным сервером SQL

Данная инструкция актуальна для клиентов с локальной установкой на выделенном сервере.

### Доступ к SQL-серверу

Для подключения к серверу используйте программу **SQL Server Management Studio** (найти в меню «Пуск»).

Два варианта авторизации:

1. **Windows Authentication** — логин и пароль не требуются, вход автоматический.
2. **SQL Server Authentication** — логин: `sa`, пароль уточните у вашего системного администратора iStom.

### Программа недоступна с других ПК

Если программа не запускается на других ПК (сообщение «сервер не найден или недоступен»):

1. Проверьте, запущена ли служба **«SQL Server»** на сервере.
2. Проверьте, запущена ли служба **«Обозреватель SQL»**.
3. Убедитесь, что **пинг проходит** с клиентского ПК на сервер и обратно.

### Резервное копирование базы данных

Рекомендуется делать бэкап **не реже одного раза в неделю**. Два способа:

1. **Через интерфейс iStom** — зайдите под пользователем «Администратор», найдите в левом меню пункт **«Резервная копия базы данных»**.
2. **Через SQL Server Management Studio** — стандартная процедура бэкапа в несколько кликов.

Бэкапы по умолчанию сохраняются в: `C:\Program Files\Microsoft SQL Server\<Имя сервера>\MSSQL\Backup`

### Восстановление на новом сервере

Для развёртывания на новом ПК потребуется:

1. Установить **SQL Server Express 2016** (или выше; более старые версии не поддерживаются).
   - При установке обязательно задайте **то же имя экземпляра**, что на текущем сервере.
   - Выберите **смешанный тип аутентификации** и задайте пароль для пользователя `sa`.
2. Переименовать компьютер на то же имя, что у текущего сервера (упрощает подключение клиентов).
3. Установить **SQL Server Management Studio** для восстановления базы из бэкапа.

!!! tip "Быстрое восстановление клиента"
    Клиентское приложение iStom можно просто скопировать (copy-paste) с любого рабочего ПК — оно не требует переустановки.
