# Обозначение кнопок

Описание кнопок программы iStom.

!!! info "Примечание"
    Изображения кнопок будут добавлены при обновлении документации.

| Кнопка | Назначение |
|--------|-----------|
| Создать | Создание документа, карты, счета или добавление данных основного уровня в ведомостях, настройках и шаблонах. |
| Добавить подуровень | Добавление подуровня в ведомостях, настройках и шаблонах. |
| Удалить | Удаление. В некоторых разделах удаление доступно по нажатию правой кнопки мыши. |
| Печать / Экспорт | Вывод на печать документов и экспорт в 1С и другие форматы. Во многих разделах имеется выбор что нужно вывести на печать. |
| Экспорт в 1С | Экспорт печатных форм в 1С и другие форматы. Кнопка доступна после нажатия кнопки печати. |
| Масштаб | Увеличение/уменьшение печатных форм для удобства просмотра. |
| Навигация по страницам | Переключение между страницами в печатных формах, а также кнопки перехода в начало и конец документа. |
| Редактировать | Редактирование данных. |
| Шаблоны | Шаблоны, прайс-листы и прочие списки с данными для заполнения разделов программы. |
| Формирование счета | Формирование счетов из плана лечения. |
| Подписанные документы | Подписанные пациентом документы (кнопка добавляется автоматически после вывода на печать первого подписанного документа). |
| Пополнение баланса | Пополнение баланса пациента. |
| Оплата | Проведение оплаты в текущем счете и ведомостях. |
| Список событий | Показ списка событий для выбранного пациента в расписании (доступна в административной вкладке карты пациента). |
| Звонок | Кнопка звонка. |
