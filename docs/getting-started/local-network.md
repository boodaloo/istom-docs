# Работа на нескольких компьютерах (локальная сеть)

Если программа установлена локально (не облако), все рабочие места подключаются к одному компьютеру с базой данных.

## Как это работает

Один компьютер выступает **сервером** — на нём установлена база данных. Остальные компьютеры подключаются к нему по сети.

Для стабильной работы серверный компьютер должен иметь **статический IP-адрес**:

- **Компьютеры в одном здании** — статический IP настраивается бесплатно в локальной сети
- **Компьютеры в разных зданиях** — статический IP подключается платно у интернет-провайдера

!!! warning "Важно"
    Динамический IP-адрес меняется при каждом подключении. Использование динамического IP может привести к нестабильной работе. iStom не несёт ответственности за проблемы при работе через динамический адрес.
