# Первоначальная настройка

После установки программы необходимо выполнить несколько шагов, чтобы подготовить iStom к работе.

## Шаг 1. Настройте организацию

Введите данные вашей клиники: название, адрес, реквизиты, логотип.

[Настройка организации →](../configuration/organization.md)

## Шаг 2. Добавьте персонал

Создайте учётные записи для врачей и сотрудников, укажите специализации.

[Список персонала →](../configuration/staff.md)
[Профессии врачей →](../configuration/doctors.md)

## Шаг 3. Настройте права доступа

Определите что может делать каждая роль: администратор, врач, регистратор.

[Права доступа →](../configuration/permissions.md)

## Шаг 4. Настройте зарплаты

Укажите вид оплаты и процентные ставки для врачей и младшего персонала.

[Настройка зарплат →](../configuration/salary.md)

## Шаг 5. Создайте прайс-лист

Добавьте услуги и цены — без прайс-листа нельзя формировать счета.

[Как создавать прайс-листы →](../modules/finance/invoices.md)

## Шаг 6. Настройте кассу (если есть)

Подключите онлайн-кассу АТОЛ для печати чеков.

[Настройка кассы →](../modules/finance/cash-register.md)

## Готово — начинайте работу!

- [Расписание](../modules/schedule/index.md) — запись пациентов
- [Карта пациента](../modules/patients/index.md) — ведение амбулаторных карт
- [Финансы](../modules/finance/index.md) — счета и оплата
